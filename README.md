# SpendWise

Smart Expense & Budget Analyzer using Python

## Features
- tracking your transaction (`transactions.csv`)
- Budget set karna aur compare karna (`budgets.csv`)
- generating monthly reports (`reports/` folder mein)

## How to Run
```bash
python main.py
```
